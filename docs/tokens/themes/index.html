Theme과 contrast

같은 semantic 경로로 light와 dark를 전환하고 대비를 검증합니다.

Theme은 component 분기문이 아니라 semantic alias 교체로 동작합니다.

Primary 기준

현재 primary는 JLCA orange palette입니다.

  • light primary.500: oklch(0.68 0.23 45)
  • dark compatibility primary.500: oklch(0.75 0.2 45)

Contrast gate

  • 기본 surface의 본문 text pair는 최소 4.5:1입니다.
  • focus indicator는 인접 색상과 최소 3:1입니다.
  • disabled 상태도 의미 전달을 색상 하나에만 의존하지 않습니다.

Component에서 raw light/dark 값을 선택하지 않습니다. 동일한 semantic 변수 경로를 유지하면 Theme 전환과 접근성 검증을 한곳에서 관리할 수 있습니다.
