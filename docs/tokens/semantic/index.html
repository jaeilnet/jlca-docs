Semantic 토큰

light·dark 테마에서 의미 이름이 가리키는 값.

동일한 의미 경로가 테마에 따라 다른 Reference 값을 가리킵니다. 두 열은 현재 light·dark JSON의 참조식과 해석한 값을 함께 표시합니다. {color.primary.700} 같은 표기는 다른 토큰을 참조합니다. 색상 견본으로 두 테마를 비교하고, 앱 CSS에서는 표시된 --color-* 등의 CSS 변수를 사용하세요.
