Reference 토큰

색상, 공간, 형태, 타이포그래피와 모션의 기본 값.

표의 소스 경로와 값은 현재 packages/tokens/src/reference/*.json에서 빌드 시 읽습니다. CSS 변수는 생성된 web CSS에 실제 선언된 이름만 표시합니다. private 경로와 변수로 노출되지 않는 참조는 내부 참조로 표시하며 앱에서 직접 사용하지 않습니다.

숫자 단계는 자연 순서로 정렬합니다. 참조식은 light·dark 레지스트리에서 풀어 색상 견본과 함께 표시합니다. Reference의 직접 값은 테마가 바뀌어도 같습니다. CSS 변수의 테마별 의미 연결과 호환 바인딩은 Semantic 토큰을 확인하세요. 표는 브라우저의 최종 computed style을 측정한 결과가 아닙니다.
