Component 카탈로그

공개된 Core component family의 API, 행동과 소유 경계를 확인합니다.

컴포넌트 위치는 재사용 횟수보다 소유하는 지식, interaction과 dependency로 결정한다. 디자인 시스템 컴포넌트는 제품 도메인과 외부 서비스 없이 fixture만으로 렌더되어야 한다.

배치 결정

Primitive

Primitive는 디자인 시스템의 최소 공개 UI 단위다. DOM 태그 수가 하나여야 한다는 뜻이 아니라, 하나의 접근성·interaction 계약을 제공한다는 뜻이다.

소유할 수 있다.

  • focus, keyboard, portal, dismiss
  • controlled/uncontrolled UI state
  • ARIA widget pattern
  • JLCA semantic token 기반 variant, size와 motion
  • native element 또는 private headless implementation

소유할 수 없다.

  • 제품 도메인 용어와 business policy
  • Query, API, mutation, auth, router, analytics
  • Composition 또는 Capability import
  • vendor component/type의 public export

Headless library는 구현 디테일이다. 소비자는 JLCA component와 JLCA props type만 import한다.

Composition

Composition은 둘 이상의 Primitive를 조합해 반복 가능한 범용 UI 문제를 해결한다.

Composition은 UI 범위의 입력·선택·open state와 명시적 callback을 소유할 수 있다. 제품 DTO, Query result, permission과 route 동작은 받지 않는다. 제품 명칭을 제거했을 때 의미가 무너지면 Composition이 아니라 Domain View다.

Composition은 Chart, Carousel, Map을 import하지 않는다. 범용 core가 선택적 vendor dependency를 끌어오지 않게 하기 위한 비대칭 경계다.

Capability package

Charts, Carousel, Maps는 core 계층의 위아래가 아니라 선택적으로 소비하는 sibling capability다.

각 package는 다음을 소유한다.

  • vendor adapter와 version-specific mapping
  • JLCA semantic token을 vendor runtime 값으로 바꾸는 adapter
  • 접근성 fallback과 keyboard/gesture 계약
  • 필요한 CSS side effect의 좁은 public entry
  • vendor에 독립적인 props, event와 data contract

각 package는 다음을 소유하지 않는다.

  • 제품 KPI, 추천 정책, 매장 상태 같은 business semantics
  • 다른 Capability package
  • 앱 Domain, Query, auth, router
  • vendor instance/type를 전파하는 public API

Chart의 series 의미, Map marker의 제품 상태, Carousel item 내용은 Domain View가 좁은 display model로 변환해 전달한다.

Public import

APPROVED CORE는 구현된 package root에서만 소비한다.

다음 CONDITIONAL CAPABILITY import는 해당 package가 생성 조건과 완료 gate를 통과한 뒤에만 허용한다.

Foundation은 app과 Storybook bootstrap에서 한 번만 적용한다. 이 entry는 현재 구현됐다.

Tailwind CSS v4 consumer는 CSS entry 위치를 기준으로 installed package dist 경로를 조정한다. Foundation import만으로는 component utility가 생성되지 않는다.

package 내부 구현 경로와 vendor package의 직접 소비는 금지한다.

현재 @jaeilnet/design-primitives에는 Layout, Typography, Form, Table과 Navigation semantic family가 구현됐다. @jaeilnet/design-compositions에는 InputField, Field, ChoiceField, FormGroup, Breadcrumb, Pagination이 구현됐다. 위 import block이 현재 Core public catalog다.

현재 public catalog는 위 두 Core package root가 정본이다. 존재하지 않는 Capability import는 구현·검증 전 production 코드에 추가하지 않는다. Navigation의 구체적인 이름·keyboard·unavailable 계약은 Navigation을 따른다.

Layout 공개 계약

  • Box는 polymorphic base와 token으로 제한된 spacing, radius, semantic color style prop을 제공한다.
  • Flex는 row를 기본으로 direction, align, justify, wrap, gap, rowGap, columnGap을 제공한다.
  • Stack은 column flow, Group은 align center와 wrap을 기본값으로 하는 row flow다.
  • Container는 breakpoint token으로 제한된 scalar max-width, auto inline margin과 SpaceToken gutter를 제공하며 fluid일 때 max-width 제한만 제거한다.
  • Center는 block 또는 inline flex에서 두 축 중앙 정렬을 고정하며 임의 align/justify 변경을 노출하지 않는다.
  • RepeatGrid는 scalar columns 1–12와 token gap, rowGap, columnGap으로 동일 너비 track을 반복한다. 선택적 responsive는 breakpoint별 columns만 덮어쓴다. Mantine의 SimpleGrid 이름과 cols prop은 복제하지 않는다.
  • Grid는 필수 scalar columns 1–12로 명시적 track을 만들고, 별도 GridItem은 필수 scalar span 1–12로 자신이 차지할 열 수를 정한다. 선택적 responsive는 각각 breakpoint별 columns와 span만 받으며 Mantine의 Grid.Col namespace API는 복제하지 않는다.
  • AspectRatio는 필수 양수 ratio를 width/height로 적용하고 요소의 너비는 소비자에게 맡긴다. polymorphic element, native attribute, ref와 Box token을 보존하되 consumer style의 aspectRatio 우회는 막는다.
  • 모든 gap과 Box spacing은 SpaceToken만 받고 native attribute와 ref를 보존한다.
  • consumer inline style은 비레이아웃 값만 허용하며 flex, grid template·placement, spacing, color 계약을 우회하지 않는다.
  • Grid 계열의 기준값은 항상 scalar prop이다. responsive는 base 없이 mobile, mobile.s, tablet, laptop, laptop.lg, laptop.xl의 min-width override만 받는다.
  • responsive Grid class는 완전한 Tailwind literal lookup으로 생성한다. dotted token은 mobile-s:, laptop-lg:, laptop-xl: variant로 변환하며 template string으로 class를 조립하지 않는다.

Space는 현재 만들지 않는다. Stack/Flex/Grid gap과 Box margin으로 실제 간격 요구를 표현할 수 있고, 조사된 빈 요소는 구분선·드래그 핸들·스켈레톤이라 spacer가 아니다. Grid의 responsive columns/span만 승인됐으며 responsive spacing·Flex 속성, offset, order와 row span은 아직 공개하지 않는다.

Typography 공개 계약

Typography Core family는 다음 여섯 개의 독립 export다.

  • TextSize = '2xs' | 'xs' | 'sm' | 'md' | 'lg' | 'xl'
  • TextWeight = 'regular' | 'medium' | 'semibold' | 'bold'
  • TextTone = 'accent' | 'danger' | 'default' | 'info' | 'inherit' | 'inverse' | 'muted' | 'secondary' | 'success' | 'warning'
  • TextAlign = 'center' | 'end' | 'justify' | 'start'
  • TextWrap = 'balance' | 'nowrap' | 'pretty' | 'wrap'
  • TextLineClamp = 1 | 2 | 3 | 4 | 5 | 6

Text는 기본 p이며 polymorphic as, native props와 ref를 보존한다. 기본값은 md, regular, default, start, pretty다. truncate와 lineClamp는 동시에 사용할 수 없고 중요한 정보의 유일한 표현에 사용하지 않는다.

Title의 필수 order=1..6은 실제 h1..h6를 정하고 선택적 size=1..6은 시각 위계만 정한다. size 1–2 기본 weight는 bold, 3–6은 semibold이며 arbitrary as를 제공하지 않는다.

Code는 기본 <code>이고 block일 때 focus 가능한 <pre><code>다. 크기는 xs | sm | md만 제공하며 syntax highlighting, copy action과 line number는 Composition 책임이다.

Blockquote는 native URL cite와 화면에 보이는 citation을 분리한다. citation은 <footer><cite>로 렌더하고 tone은 default | accent만 제공한다. 장식 인용부호는 CSS presentation이다.

List는 type="ordered | unordered"에 따라 실제 ol | ul을 렌더한다. ordered marker는 decimal | lower-alpha | upper-alpha, unordered marker는 disc | circle | square, spacing은 none | xs | sm | md | lg다. ordered만 start와 reversed를 받으며 별도 ListItem은 native li와 value를 보존한다. List.Item namespace와 custom icon marker는 제공하지 않는다.

Typography가 소유하는 color, font family/size/style/weight, letter spacing, line height, 정렬·wrap·축약과 native 구조는 public style로 우회할 수 없다. Foundation이 설치한 generated token 변수만 소비한다.

Table 공개 계약

Table semantic family는 native HTML table model을 그대로 드러내는 열한 개의 독립 export다.

ExportNative element책임
Tabletabledensity, border, stripe와 table layout
TableCaptioncaption표를 식별하는 제목과 caption side
TableColumnGroupcolgroup열 집합과 span
TableColumncol열 span과 width/min-width/max-width
TableHeadertheadcolumn header row group
TableBodytbodydata row group
TableFootertfootsummary/footer row group
TableRowtrnative row
TableHeaderCellthrow/column/group header association
TableCelltddata cell과 explicit headers association
TableScrollAreadiv이름 있는 opt-in horizontal overflow region
  • Table 기본값은 density="default", borders="rows", layout="auto", striped={false}다. density는 compact | default | relaxed, borders는 none | rows | grid, layout은 auto | fixed다.
  • TableCaption.side는 top이 기본이며 bottom을 선택할 수 있다. 넓은 표의 scroll 시작점에서도 제목이 보이도록 caption text는 logical start 정렬을 소유한다. cell의 align은 start | center | end, verticalAlign은 top | middle | bottom이고 각각 start, middle이 기본이다.
  • TableHeaderCell.scope는 col | row | colgroup | rowgroup의 필수 prop이다. 복합 header는 native id, headers, rowSpan, colSpan을 보존해 명시적으로 연결한다.
  • Table은 숨은 wrapper를 만들지 않는다. overflow가 실제로 필요할 때만 TableScrollArea를 추가하며 aria-label 또는 aria-labelledby로 반드시 이름을 붙인다. region은 기본 tabIndex={0}과 visible focus를 제공한다.
  • component가 소유하는 typography, color, cell padding, border, table layout과 overflow/focus style은 raw style로 우회할 수 없다. TableColumn만 열 설계용 width, min-width, max-width를 허용한다.
  • Table은 정적인 tabular data를 위한 native structure다. sorting, selection, editing, virtualizing, cell keyboard navigation, data fetching과 pagination은 제공하지 않는다. 이런 interactive DataGrid는 별도 ARIA composite widget과 product-data 설계가 필요하다.
  • 좁은 화면에서도 table, row group, row, cell display를 바꾸거나 card DOM으로 변환하지 않는다. 필요한 경우 의미 구조를 유지한 채 이름 있는 TableScrollArea로 overflow를 제공한다.

canonical import는 위의 @jaeilnet/design-primitives다.

Button 공개 계약

  • Button, ButtonProps, ButtonVariant, ButtonSize, buttonVariants를 package root에서 제공한다.
  • primary, secondary, danger, success, outline, ghost, link는 JLCA semantic action/content 역할만 소비한다.
  • hover, pressed, disabled, focus와 motion은 light/dark에서 동일한 semantic path를 사용한다.
  • Radix Slot과 class merge 구현은 package-private이며 vendor type을 공개하지 않는다.
  • asChild는 링크 같은 단일 자식의 native semantics를 보존한다. native disabled 동작은 실제 button element가 소유한다.

Input 공개 계약

  • Input, InputProps, InputStyleProps, inputVariants를 Primitive package root에서 제공한다.
  • default, hover, focus, invalid, disabled, read-only와 file 상태가 semantic surface/content/border/focus/feedback 역할만 소비한다.
  • native input attribute, event와 ref를 그대로 전달하며 field label/help/error 조합은 소유하지 않는다.
  • 기존 palette class와 CVA type은 public API에서 제거하고 styling vendor는 package-private으로 유지한다.

InputField 공개 계약

  • InputField, InputFieldProps를 Composition package root에서 제공한다.
  • Box, Stack, Group, Input, Button을 조합하며 raw div, 제품 상태, form library와 icon vendor를 직접 사용하지 않는다.
  • required, label, description, 모든 error id, 외부 aria-describedby와 input ref를 연결한다.
  • password visibility action은 native button이며 keyboard focus, aria-controls, aria-label, aria-pressed를 제공한다.

파일 구성

Composition도 같은 public/private 규칙을 사용한다.

모든 component가 파일을 억지로 나눌 필요는 없다. public index.ts는 component, 소비자용 prop type과 안정된 variant만 노출하고 helper, vendor adapter와 fixture는 숨긴다.

상태와 접근성 책임

대상상태·접근성 책임
Primitivewidget keyboard/focus/ARIA, disabled/pressed/open 상태
Compositionlabel-description-error 연결, 그룹 의미, 복합 읽기 순서
Capabilitycanvas/SVG 대체 콘텐츠, gesture와 keyboard fallback

Primitive를 사용했다는 사실만으로 상위 프로덕트 계층의 접근성이 완료되지는 않는다. Domain View, Section과 Page의 책임은 consuming application architecture가 소유한다.

Design System과 Domain View 경계

다음 중 하나라도 참이면 앱 Domain View에 둔다.

  • Lotto 구매, 매장, 추천, 계정처럼 제품 어휘를 사용한다.
  • 한 use case의 loading/empty/error/success 의미를 표현한다.
  • Domain Model을 전제로 한 레이아웃이나 문구를 가진다.
  • 여러 Capability를 제품 의미로 조립한다.

Domain View도 순수 UI여야 하지만 디자인 시스템의 공개·버전·의존성 정책에는 포함하지 않는다. 전체 연결 규칙은 consuming application architecture를 따른다.
