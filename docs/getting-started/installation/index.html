설치와 인증

GitHub Packages 인증과 공개 패키지 설치.

JLCA의 공개 패키지는 GitHub Packages의 @jaeilnet scope에서 설치합니다. 패키지와 저장소 접근 권한이 필요합니다.

Registry 설정

앱의 .npmrc에 다음을 넣습니다. 실제 토큰은 파일에 기록하지 않습니다.

로컬 셸이나 CI secret store에서 NODE_AUTH_TOKEN을 제공합니다. GitHub Packages 읽기 권한과 비공개 패키지 접근 권한을 확인하세요.

패키지 설치

현재 소스 manifest 버전은 아래와 같습니다. 설치 전 registry에 같은 버전이 있는지 확인하세요. 제품에서 Lotto UI가 필요하지 않으면 마지막 패키지는 생략합니다.

비공개 design-tokens, design-foundation, design-core는 소비자 설치 대상이 아닙니다. 이 문서의 토큰 표는 값을 공개하지만 패키지 import 경로를 제공하지 않습니다.
